An original offline third-person 3D open-world crime game for the [Make GTA 6 bounty](https://make.fun/bounty/gta6-01). Explore a sun-bleached coastal metropolis on foot and by car, steal vehicles, outrun five wanted levels of police, and work through four linked jobs for Nia Vale, Rafa Solis, Ines Marlow and Ada Cruz.

The entire city, every texture, vehicle, pedestrian and sound is generated procedurally from the authored code in `game/src/`. Three.js r160 is vendored locally; nothing is fetched at runtime.

Play locally with `node serve.ts`, then open `http://localhost:8080`. Build the dossier with `MAKEFUN_OUTPUT_DIR=out node main.ts`.
